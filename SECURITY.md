# Security Policy

## Supported Versions

| Component | Version | Supported |
|---|---|---|
| Android App (`/app`) | 1.0.0 | :white_check_mark: |
| Backend API (`/backend`) | 1.0.0 | :white_check_mark: |
| Web Admin (`/admin-panel`) | 1.0.0 | :white_check_mark: |
| WireGuard Agent (`/agent`) | 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities directly to **security@nsecvpn.com**.
Include reproducible steps, environment details, and proof-of-concept payloads.
We will coordinate remediation prior to public disclosure.
