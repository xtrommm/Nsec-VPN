# Nsec VPN Administrator Guide

The Web Admin Console (`https://admin.nsecvpn.com`) provides centralized management for all VPN server nodes, anonymous client registrations, remote configurations, and security audit logs.

---

## 1. Authentication & Role Permissions

The console supports two role tiers:
- **SUPER_ADMIN**: Full access including Node Deletion, Administrator User Provisioning, and Immutable System Audit Log inspection.
- **ADMIN**: Operational access for registering new nodes, managing client device VIP tiers, and updating AdMob / version policies.

Login is protected by bcrypt password hashing and rate-limiting (maximum 5 attempts per 5 minutes).

---

## 2. Managing WireGuard Nodes

### Adding a Node
1. Navigate to the **WireGuard Nodes** tab.
2. Click **Add New Node**.
3. Fill in:
   - **Node Name**: E.g., `US East (New York)`
   - **Country Code & Flag**: E.g., `US`, `🇺🇸`
   - **Endpoint**: Host and WireGuard UDP port (`us.nsecvpn.com:51820`).
   - **Server Public Key**: 44-character Curve25519 key generated by the installer.
   - **Agent URL**: HTTP endpoint of the node daemon (`http://198.51.100.24:51821`).
   - **Agent Shared Secret**: HMAC secret printed by the install script.
   - **Tier**: Check **VIP Subscribers Only** for high-speed 10Gbps dedicated clusters.

### Live Health Verification
- Click the **Pulse Activity** icon on any server row to query the agent in real time.
- The system returns live active peer counts and instantaneous CPU load percentage.

---

## 3. Client Devices & VIP Tiers

- **Search by UUID**: Search client hardware IDs without storing personal identifiable information.
- **Grant VIP Access**: Elevate users to VIP status manually for testing or customer support.
- **Block Device**: Block malicious hardware UUIDs from establishing tunnels.
- **Export CSV**: Download an aggregated, strictly anonymous CSV of global connection counts.

---

## 4. Remote Config & Monetization Toggles

- **Google AdMob Toggles**: Enable or disable Banners, Interstitials, and Rewarded Ads on the fly without releasing new APK updates.
- **Minimum App Version Code**: Enforce mandatory app upgrades when older versions are deprecated.
- **Network Emergency Alerts**: Display instant notifications on the mobile client Home screen.
